# Cortes Virais BR — entrada para o Claude

Usar este projeto quando o usuário solicitar pesquisa, seleção, edição ou entrega de cortes e indicar este repositório. Distinguir esse pedido de uma tarefa de desenvolvimento ou revisão do próprio código.

Ler os arquivos compartilhados nesta ordem, conforme o acesso disponível:

1. [AGENTS.md](AGENTS.md): regras de trabalho e evidência.
2. [README.md](README.md): estado real do projeto.
3. [config/project.json](config/project.json): decisões confirmadas.
4. [Skill principal](skills/cortes-virais-br/SKILL.md): ordem da tarefa e referências sob demanda.
5. [Guia de execução](docs/execucao.md): recursos necessários e continuidade.

Manter as decisões no arquivo compartilhado de configuração, evitando uma cópia diferente de preferências para o Claude. Respeitar a instrução explícita mais recente do usuário.

Trabalhar sobre o material indicado ou fazer descoberta livre, conforme a tarefa. Verificar acesso ao repo, pesquisa, mídia, terminal e ferramentas antes de prometer execução. Um link do GitHub pode servir de ponto de entrada, mas não comprova que os arquivos foram lidos nem que há acesso ao computador do usuário.

Estado atual: instruções e pesquisa em construção; pipeline de vídeo e execução no Claude ainda não validados. Usar somente comandos/componentes que realmente existam. Se faltar uma capacidade, continuar as etapas independentes e dizer exatamente o que impede concluir a etapa restante. Diferenciar plano, render e entrega verificada.
